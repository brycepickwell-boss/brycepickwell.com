# brycepickwell.com

Static site, no build step, no framework, no JS dependencies. Just HTML/CSS files.

## Pages
- `index.html` — homepage (bare, centered: name, email, About/Work/Blog nav)
- `work.html` — career timeline
- `about.html` — placeholder bio, needs your real copy
- `blog.html` — empty placeholder

## Run locally
python3 -m http.server 8000
then visit http://localhost:8000
