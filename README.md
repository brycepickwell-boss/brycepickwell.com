# brycepickwell.com

Static site, no build step, no framework. Just one file right now.

## Pages
- `index.html` — name, email, centered. That's it for now.

The full four-page version (Work timeline, About, Blog with photo
grid) is archived separately, not currently live.

## Run locally
python3 -m http.server 8000
then visit http://localhost:8000

## Deploy
Push to this repo. Vercel is already connected and redeploys
automatically.
